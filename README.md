# Calculadora de IMC — JavaFX

Aplicação de uma **calculadora de IMC (Índice de Massa Corporal)** desenvolvida em **JavaFX** e **Scene Builder**.

## Sobre o projeto

A aplicação possui uma interface gráfica composta por **Sliders, Labels e TextFields**, permitindo ao usuário informar seus dados e realizar o cálculo do IMC.

Os resultados são armazenados em uma **tabela**, possibilitando a realização de consultas aos registros posteriormente.

## Funcionalidades

* Inserção de peso e altura;
* Utilização de Sliders para seleção dos valores;
* Cálculo do IMC;
* Exibição do resultado e classificação e armazenamento dos dados em tabela;
* Interface gráfica desenvolvida com JavaFX;
* Interface construída utilizando Scene Builder.

# Editor de Imagens — JavaFX

Aplicação de **edição de imagens** desenvolvida utilizando **JavaFX** e **Scene Builder**.

## Sobre o projeto

O projeto permite que o usuário **selecione uma imagem de sua escolha** e aplique diferentes operações de edição diretamente pela interface gráfica.

## ⚙️ Funcionalidades

* Selecionar e carregar uma imagem;
* Espelhar a imagem horizontalmente;
* Converter a imagem para **Grayscale**;
* Converter a imagem para **preto e branco (B&W)**;
* Visualizar a imagem após as alterações;
* Interface gráfica desenvolvida com JavaFX;
* Interface criada utilizando Scene Builder.

## 🎯 Objetivo

O objetivo do projeto é aplicar conceitos de **manipulação e processamento de imagens**, além de conceitos de **programação orientada a objetos** e desenvolvimento de **interfaces gráficas com JavaFX**.

## 📷 Operações disponíveis

| Operação                    | Descrição                                   |
| --------------------------- | ------------------------------------------- |
| 📂 Abrir imagem             | Permite selecionar uma imagem do computador |
| 🔄 Espelhar horizontalmente | Inverte a imagem horizontalmente            |
| 🌑 Grayscale                | Converte a imagem para tons de cinza        |
| ⚫ B&W                       | Converte a imagem para preto e branco       |
